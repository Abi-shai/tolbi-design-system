# VerificationCodeInputField

Champ de saisie de code OTP ou de vérification. Affiche N cellules de saisie individuelles avec auto-avancement, support du paste et navigation clavier.

## Comportement clavier

| Touche | Action |
|---|---|
| Chiffre 0-9 | Saisit et avance à la cellule suivante |
| `Backspace` | Efface et recule à la cellule précédente |
| `←` / `→` | Navigue entre les cellules |
| `Ctrl/Cmd+V` | Colle et distribue le code sur toutes les cellules |

---

## v-model + événements

```vue
<VerificationCodeInputField
  v-model="code"
  :digits="6"
  size="md"
  label="Secure code"
  hint="Check your email."
  @complete="onComplete"
/>
```

| Événement | Payload | Déclenché quand |
|---|---|---|
| `update:modelValue` | `string` | À chaque frappe |
| `complete` | `string` | Toutes les cellules remplies |
