# ModuleIcon

Icône représentant un module produit Tolbi. Chaque module a son propre SVG bundlé — aucune dépendance réseau à l'exécution.

## Modules disponibles

| Module | Description |
|---|---|
| `Carbone` | Suivi d'empreinte carbone |
| `Source` | Traçabilité des approvisionnements |
| `Call` | Collecte terrain par appel |
| `Scan` | Collecte terrain par scan |
| `Data` | Gestion et analyse de données |
| `ID` | Identification des producteurs |

## Tailles

La prop `size` accepte un nombre (px) ou une string CSS (`"2rem"`, `"100%"`).

<Canvas of={ModuleIconStories.Small} />

## Usage

```vue
<ModuleIcon module="Carbone" :size="48" />
<ModuleIcon module="Survey" :size="32" />
```

---

## Règles d'usage

- Toujours accompagner d'un label textuel dans l'interface — le composant expose `aria-label` mais reste insuffisant seul
- Ne pas redimensionner en dessous de `24px` — les détails visuels deviennent illisibles
- `Eudr` n'a pas encore d'asset graphique — affiche un espace vide
